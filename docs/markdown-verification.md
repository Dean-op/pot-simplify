## 真实桌面验收

运行 `pnpm tauri dev`，通过 WebView2 调试端口连接原生 `translate` 窗口。运行时为 WebView2 157.0.4341.42，原生窗口宽度为 350px；并非普通浏览器页面验收。

为保证确定性，临时覆盖页面内的配置读取，使 OpenAI 实例连接本地固定响应服务；没有保存测试服务配置，也没有调用用户配置的付费 API。桌面测试仍使用真实 Tauri IPC、HTTP、剪贴板和 Shell。

| 检查项                                               | 结果与证据                                                      |
| ---------------------------------------------------- | --------------------------------------------------------------- |
| 标题、加粗、列表、引用、代码、表格、任务列表、删除线 | 在真实译文卡片中渲染                                            |
| 预览/源码切换                                        | 源码与固定响应逐字相同；新请求默认回到预览                      |
| 原文编辑区域                                         | 仍为可编辑 textarea，未改成预览                                 |
| 复制                                                 | 点击卡片复制按钮后，原生 `readText()` 与原始 Markdown 完全一致  |
| HTTP/HTTPS 链接                                      | 点击后默认 Chrome 出现 `Example Domain` 窗口，Tauri 页面未导航  |
| 流式响应                                             | 实时渲染，不添加临时下划线                                      |
| SSE/UTF-8 分片                                       | 本地 HTTP 响应按单字节发送，中文及代码内的 `data:` 完整保留     |
| 非流式响应                                           | 使用 Tauri 原生 HTTP 访问本地服务，预览正常                     |
| 普通译文                                             | 保留普通文本与换行                                              |
| 词典卡片                                             | ECDict 实际查询 `hello`，音标、释义、词形和例句仍按词典结构显示 |
| 浅色/深色主题                                        | 使用现有主题变量显示                                            |
| 宽表格、长代码                                       | 在内容容器内横向滚动，350px 窗口无整体横向溢出                  |
| 收起/展开                                            | 收起后内容高度为 0，展开后源码未丢失                            |
| HTML、远程图片、危险/相对链接                        | 无 script/img/危险 anchor；未产生远程图片请求                   |
